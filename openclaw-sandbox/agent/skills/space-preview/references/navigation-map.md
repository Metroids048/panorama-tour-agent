# 地图与多点位导览

沿当前项目父版继续，保留站点 ID、原图、开场、原目标和所有已确认方向。地图负责选地点、显示当前观看地点和定位当前地点；地图切景不代表沿通道到达，也不生成步行记录。

## 访客信息与操作

- 地图使用位置标记和当前地点高亮，不显示内部站序数字。名称在悬停、聚焦或选点时显示；展开图的通道示意可显示名称。点位目录可保留全局数字用于查找，但数字不代表地理顺序、距离或推荐走法。真实门牌、楼层和地名中的数字保留。
- 按钮说明实际动作：直接切景用「前往／查看＋地点名」，仅转动视角用「朝向＋地点名」。不把「找回程箭头」或数组前后位置当作所有场景的导航模型。分支地点按本点已确认通道提供目的地；固定路线可优先显示既有路线方向。
- 地图和地点目录默认收起，地图、目录及说明可收起，展开后仍可返回。定位的是当前观看点，不是设备 GPS。楼层／区域切换只换地图；跨层通道按实景证据另验。

## 鸟瞰底图与人物位置

优先使用有来源且可交付的鸟瞰图、楼层图或道路底图，以建筑、庭院、房间或道路帮助访客认位置。位置有依据时使用 `kind:"located"`（默认值），保留真实坐标、比例和方向。没有可靠平面图时，可用经核实的地点、物理楼层和连接绘制 `kind:"schematic"` 的非比例空间示意；source 写明依据及未知范围，页面显示「游览示意 · 非比例」。示意轮廓只用于辨认区域，不声称恢复了墙体、尺寸、方位或真实道路；不能把猜出的测绘图或图片数组网格包装成鸟瞰地图。完全缺乏空间依据时仍回退到下述有名称的通道图。

地图保持固定方向。一个人物标记代表当前已加载的观看地点，其他可选地点用安静的点标记，不显示内部编号、放射扇形或未经标定的朝向。点地图只请求切景；新场景加载成功才移动人物和当前楼层，加载失败保留源站人物位置。浏览其他楼层不在那里伪造人物，「定位当前地点」回到当前实景所在楼层。密集点聚合涉及当前地点时，每次合并都按当前点的确切坐标计算后续碰撞，不能先按平均位置聚合、最后才挪回当前点而与其他标记相撞；人物仍锚定当前地点的确切坐标，不能移到聚合平均位置；点开可放大或按完整名称选点。

鸟瞰底图上不叠加穿越墙体／庭院的直线连网；图上有位置不证明可通行，实景箭头仍按确认通道往返。小地图保留可读的空间范围，展开图可看全图、选点和切层；示意定位保留整区参照；带底图名称的紧凑图以人物为中心打开可读周边，全图与展开另看整体，不能将名称随整图缩成小字。细长真实位置图定位恢复当前周边。紧凑小地图只常显当前地点名称，其余名称在悬停或键盘聚焦时显示；展开桌面示意可显示完整名称，窄屏展开仍避免名称相撞，完整目录保留可选地点。控件、图形、地点名称与人物分层，桌面和320窄屏均核可用图面尺寸及名称遮挡，防止 flex 样式把底图压成小团。实际保存版检查各楼层、全部地点、沿实景切站及回程后的人物对位；辅助样机只证明组件行为。

当前名称接近底图边缘时自动换到人物上方并横向避让，完整文字仍在地图裁切区域内。窄屏展开图须给楼层选择、图面与定位按钮各自空间，不能沿用紧凑小图的高度上限导致底图溢出并拦截定位点击。实际检查除元素边界外，还要正常点击定位；不能强制点击被底图挡住的按钮。

## 空间理解与原片绑定

先核入口、房间相邻关系、门洞、走廊及楼梯两端，再选图形。不得把相互分离的同尺寸房间块或站序网格当作楼层图。经核对的非比例游览图应表达连续参观空间和真实连接；轮廓只是解释已确认关系，不声称测量了建筑。无整层依据时只画已覆盖局部，不补未知房间或门。

同一楼梯上下层使用一致图上锚位并标明各自去向；不同楼梯、独立上层目的地必须分开。入口前庭可与一层共图，但物理楼层记录仍与站点一致。浏览别层时保留“当前实景楼层＋地点”，另提示正在查看的楼层；不能因地图切层移动人物。名称须可直接辨认，不把所有地点隐藏成无名点。已在底图排好名称时设 `labels_embedded:true`，播放器保留可访问名称但不重复覆盖一层浮动标签。核对人物是否挡住印在图上的名称。窄屏默认图面也要能读名称：按原图文字大小检查实际显示字号，必要时围绕人物放大周边，不靠用户先猜测无名圆点；保留全图、拖动及展开入口。

从 GPS 或照片表导入坐标必须按稳定站点 ID 和该站实际原片绑定，不能 zip 当前站序与旧坐标表。`navigation_map.places[].source_file` 填对应站 files 中的确切路径，实际保存入口会拒绝原片不匹配；该检查验证绑定，不验证坐标真伪。补图、择优或重排时重新核来源哈希与地标，保留原 GPS 投影；不能把显示错误当样式问题修。

视觉验收同时对照图面、源实景和已确认通道：入口到达、每个分支去回、两楼梯上下各一次、楼层浏览再定位、全部点位、失败保留位置。技术点击成功只证明可切站，不证明平面准确或首次访客看得懂。

## 空间位置与排序

有用户提供或已核对且可使用的位置图时，保留真实图形、宽高比及 x/y 坐标。不能按照片数组或为了排整齐移动地点。密集位置使用单一放大标记，不显示内部编号或三个相叠圆点。支持拖动、缩放和全图复位；点击聚合点放大相邻区域，地点列表与底图分区显示，每个地点仍可按名称实际点中。列表不得覆盖底图，不能出现整屏空白选择层；中等宽度窗口也须核对。展开地图按可用高度显示全图，少量点的通道示意不拉成长线填满整屏。当前地点落在密集区域时，聚合标记也须高亮。选择当前地点、选择其他地点或关闭地图后都清理临时选择面板，重开不得挡住点位。

细长位置图的小地图先聚焦当前地点周边，避免把长线路缩成难辨的细条；展开图先完整适配全线路，「定位当前地点」恢复可读周边，仍保留拖动、缩放与全图操作。

真实位置图和非比例示意共用手势：触屏双指张合缩放、单指拖动，缩放围绕双指中心；滚轮按实际滚动量连续缩放，并保持指针所指位置。边界约束仍生效。抬起一指后继续拖动不跳位，手势从地点标记开始也不能误切站；取消手势后，普通点选、键盘选点、全图及定位仍能使用。开发回归使用真实浏览器触摸／滚轮事件，并在确切下载版复验；模拟触屏不代表真机验收。

GPS 点位图仅代表拍摄位置，不代表可走道路；点间的直线也不自动成为通道。优先核对可离线交付、带道路或建筑参照的真实底图；按原 GPS 投影范围对齐，不能为了适配底图挪点。仅有散点时明确其定位参考范围。原底图带拍摄编号或过时图例时，使用有依据且许可明确的无内部编号底图，复核图内文字与网页实际行为一致；没有则如实说明底图编号来源，不改造真实地形冒充地图。数据来源、取得日期和许可须保留，当前底图不证明历史照片中的通路今天开放。访客地名不再附上传文件编号，原文件名和来源保留。

没有可依据的空间底图或明确标注的空间示意时，省略 plan 和 x/y，明确显示「通道图 · 非建筑平面」。布局依据全部已确认连接、入口和楼层，环路也参与分支排序，去回同一连线不重复绘制；当前点及相邻通道高亮，其他路径弱化；展开或切换楼层重新适配全图。不按照片数组排网格；不猜房间方位、墙体或道路。示意保留地点名称，不把已知地点聚成抽象图标；桌面空间足够时先完整显示可读的分支名称和线性末端，不因过度放大把两侧地点或终点裁掉；两点小地图应同时显示两个可读名称，纵向间距随层级保持紧凑；小地图定位时只显示当前地点及相邻连接，避免远点名称在边缘露出残片；拖动、缩放或全图后恢复其余地点，展开图始终保留全图探索；五个以上分支或周边不能在可读字号下容纳时，小地图使用当前地点与相邻地点两列选项，不画裁断的辐射线、不隐藏目的地；展开保留完整通道图；窄屏先显示可读的当前地点及相邻连接；当前点与相邻一排能够容纳时一起居中；窄屏可轻度缩小周边，但保留完整名称和可读字号，横向与纵向都不能裁成半张，可拖动看其余部分，「全图」另提供整体概览，「定位当前地点」恢复可读名称。缩放按钮占独立一行，不能盖住地图或地点名。相邻楼层的实际通道端点可作为带名称的连接入口显示，名称同时带实际楼层，避免混作本层房间。连线始终与当前可见标记相接，真实位置图聚合时隐藏组内线并把组间线接到聚合标记，缩放和展开后重新检查；示意的线长与方向不表示真实距离和朝向。

固定路线目录沿已确认路线排序；分支场景目录按区域和已确认通道组织，保留稳定 ID。解释排序时区分上传顺序、用途编排、GPS 位置及通道示意，不能声称所有布局均由照片推算。照片视觉可辅助核门位，不能单独恢复可信的整层平面。

非场馆的分支参观须在清单根字段声明 `route_connections:[{from_id,to_id},…]`，去回各一条；各站 links 的证据、角度和 view_revision 不变。程序检查声明覆盖全部站点、每条方向就绪和从入口可往返，地图按实际导出连接布局。该声明不能代替通路核对，不能用于把关闭门、石栏或相似视角接成可走路线。

## 既有数据与交付

场馆使用 venue.levels[].plan/source、venue.places[].station/level/x/y；x/y 为有依据的 0–1 图上相对坐标；`venue.levels[].kind` 和 `navigation_map.kind` 区分 `located` 与 `schematic`，示意坐标只在对应示意图内有效。无图场馆仍填写真实物理 floor，所有站须从入口沿已确认通道可达；跨层成品核实楼梯两端。不得用示意绕过错误坐标或缺通路。

校园和线性导览可用：

```json
{"navigation_map":{"name":"北门至图书馆位置图","plan":"map.jpg","source":"用户提供的校园图，拍摄位置经确认","places":[{"station":"gate","x":0.2,"y":0.4},{"station":"library","x":0.75,"y":0.3}]}}
```

plan 使用当前清单的相对图片路径或已管理的 originals 路径；station 为真实稳定 ID。navigation_map.source 最多 220 字，保存前核长度，简短保留作者／数据方、许可、日期、定位依据和必要范围；完整出处另存任务记录，不删许可或改判定来适配。未定位点保留目录，不猜坐标。地图内嵌到同版 HTML，新增地图不改原通道或原目标。固定路线跳点仍保留既有有效日期与阻断限制。

开发复验以实际下载件检查两种约定桌面尺寸：首屏提示完整、目录与地图不重叠、每个楼层／区域、全部地点实际点选、当前点定位、密集点展开、无纯数字标记、全图可见和通道线端一致；再沿实际画面箭头逐方向试走。DOM 数量、工程样件和模型评分均不能代替同版真实网页验证。
## 无底图时的受限绘图入口

空间关系有依据时，在 navigation_map 或 venue.levels[] 写 kind:"schematic"、source、schematic，省略 plan。程序把区域和通道绘成内嵌 PNG，制作 Agent 无需代码或外部绘图工具。示意表达已核实的连续区域关系，不是测绘墙体；形状大小与图上方向不代表实测。没有空间依据仍只能交通道图，并说明地图目标未完成。

```json
{"navigation_map":{"name":"已覆盖房间游览示意","kind":"schematic","source":"据用户空间说明及两端实拍核对；非比例，未覆盖区域未绘制","schematic":{"areas":[{"name":"入口区","polygon":[[0.08,0.2],[0.4,0.2],[0.4,0.8],[0.08,0.8]]},{"name":"展厅区","polygon":[[0.4,0.2],[0.9,0.2],[0.9,0.8],[0.4,0.8]]}],"paths":[[[0.25,0.55],[0.65,0.55]]]},"places":[{"station":"gate","x":0.25,"y":0.55},{"station":"hall","x":0.65,"y":0.55}]}}
```

全部坐标为0–1，区域 polygon 为3–40个顶点；paths 为已核通道的折线（每条2–40个点）。区域最多32，通道最多64。名称位于区域左上；站点放通行区域中，避免盖住区域名。不要照抄示例坐标：依据本任务关系分别画入口、分支区域和通道。没有可靠比例不能使用 located。已有可用官方地图优先用 plan，室内不清楚可另绘已核局部示意；不能同时填 plan 与 schematic。

# 地点选择与步行提示

独立地点目录、小地图打开时暂时收起底部步行提示，关闭、选点后恢复；展开地图使用自己的地图与地点分区。实际下载件在 1280、820、390、320 像素宽检查打开、关闭、Escape、选点及恢复，面板在视口内仍须检查是否遮挡其他控件。

# 场馆总览：先选楼层或区，再看实景

- 用户想知道各层有哪些区域、能点开哪些实景时走这个分支。楼层或分区可以并列显示，但名称写清物理楼层。仅有部分区域就写清边界。只有图像主题、栏杆或相似布展时，物理楼层保持待确认；先保存临时看景点，问一次这几组图分别在哪层。同一任务从父版调整分组时保留图片与站点 ID，不靠换层入口生成通路。只有普通照片则看单视角；缺平面保留分区列表，缺照片可给明确标记的平面；缺通行证据不能生成箭头。图纸只做分层示意，不生成三维。
- 进入实景后保留切换已有楼层或分区和返回总览的入口；即使没有下一支箭头，也可换景或回总览。若缺跨层两侧实景证据，只交「分层预览」或总览草稿，说明切换是浏览操作。不要用直接换景补实地通路。
- 照片和图纸从当前会话的输入取，用当前任务目录。如果用户给了当前会话的资料包绝对路径和准备好的清单，可直接读取清单，核对是这批资料后用其相对路径，保留已有来源、分区和方向证据。每个点写实拍所在物理层/区、画面朝向；约 2:1 只提示球面，确认内容后才用 `spherical:true`。核对照片和图纸授权。公开图纸只能核结构时，不能嵌入；自行绘制的非测绘位置示意标来源及范围。第三方授权图在 `attribution` 写作者、许可、来源和所做变更。
- 清单根字段 `title,stations,venue`（和可选 `attribution,entry`）。`venue:{coverage,opening_level,levels,places,connections,recommended}`。各层 `{id,name,plan,source,areas}`，其中 `plan` 是 PNG/JPEG/WebP 输入路径；缺图可省略 `plan`，有图须填 `source`。`areas` 是只有示意的区域，元素 `{name,note,x?,y?}`。点位 `{station,level,x?,y?}`，坐标为所用平面左上原点的 0–1 比例。`recommended` 只填少量真正值得先看的站 ID，首项是用户指定的第一站，所有其他实景仍可在楼层或分区里选看。`overview_note` 最多 90 字，只写一条关键范围说明。
- 平面留白过多时可给该层写 `plan_crop:[left,top,right,bottom]`，使用未裁原图的 0–1 坐标；点位也继续填未裁原图坐标，导出会换算。检查楼层图编号与实景卡片对应，裁边后仍能读出方向和位置。原图不够定位时保留列表，不猜点位。
- 用户明确要看多个物理楼层或跨楼层走访时，在 `venue` 设 `require_cross_floor:true`，每项 `levels` 用 `floor` 填现场确认的物理层。同层各区使用相同的 `floor`（例如均为 `3F`）。跨层证据缺失时仍可保存总览草稿，正式交付须从入口能走到已核对的物理跨楼层连接。
- 通路写 `{from,to,name,access,hours,audience,pending?}`，双向须分别填写。未核对写人能看懂的 `pending`，同时省略该方向画面箭头。核对时看两侧实拍的通道、开放限制、时段与人群；当事人或原作者的独立方向证据写在源站 `links:[{to_id,yaw,pitch,view_revision,confirmed_by,evidence,cue?}]`。绑定的是当前源球面版本；完整已确认球面首次导入可加 `--bind-spheres`，不必手填 `view_revision`。源画面没有可用的通道方向时留在待核对。推荐和自由选点都不代表实际能从当前位置通行。
- 用 `python3 /workspace/app.py --project <本会话项目> --manifest <清单> --port 18792` 保存。首行给回执的 `review_url`，说明覆盖范围及一处实质缺口，保留 `recover_url`。未过门槛要取件时，加 `--preview-download`，清楚标「总览草稿」。当用户要交付且有清晰点位和层/区平面、能按箭头进入确认的跨层/区连接和分支时，用 `--require-venue --chat-download`，多物理楼层的交付和同版取件再加 `--require-panorama`。用 `review_url`「打开场馆总览」和 `download`「下载离线导览」交付同一保存版。如只含同一物理层的多个区，明说没有实拍跨楼层。不要拿别的地点或历史样件替代。
- 继续同一任务先用 `--project <项目> --resume --port 18792` 找当前保存版。只换推荐点时用 `--parent <父版> --venue-recommended <站ID...>`，只换总览默认层用 `--parent <父版> --venue-level <层ID>`；可同时加取件参数。补通路时读取回执 `manifest`，保留原片、平面和其余方向，按父版另存。取回旧版只读用 `--resume --parent <旧版>`。断流先找原任务，不重新收图；公开发送和手机打开未经验证时不可报已完成。
- 交付前打开保存版，在手机窄屏确认首屏能点实景和推荐看点，进场能辨认地点，点去向后当前屏幕可直接点实景箭头。总览的连接来自已核对方向。公开球面若有多个分辨率档，先核馆方最高档及授权，优先取原发布细节。短的范围缺口可写在清单的 `venue.overview_note`。只走通点击或拿到文件回执，不能代替画面和体验核查。

5. 用户已经说「发给别人看」「给我可发的版本」且路线通过成品门槛时，直接交付当前保存版；不用追加一次同意才能制成文件，也不代替用户向第三方发送。调用 `--resume --parent <确切保存版> --require-tour --chat-download --port 18792`。先把回执的 `review_url` 和 `download` 写成「打开全景预览」和「下载离线导览」链接，再给一段可以原样转发的访客话术，含起点怎么认、去程怎么走和何处停、原路回程。使用能在图里找到的地标，省掉内部操作、文件大小和版本号。用回执的 `route_card_url` 给同版「打开实景路线图」链接。OpenClaw 桌面不在正文显示 MEDIA 路径；直接下载链接无需解压。链接仅在当前电脑有效，转发用保存后的文件和实景图。离线 HTML 需保存后用浏览器打开。成品门槛和附件哈希以回执为准，日常交付无需让制作方等待浏览器回归；仅陈述实际验证。仍有方向待核对时，保留已证实的范围。用户已表示要离线看或发给别人时，当轮用 `--preview-download` 给允许取件的同版预览，说明哪些地方只能看图。固定步行草稿按其规则给冻结试走链接。
